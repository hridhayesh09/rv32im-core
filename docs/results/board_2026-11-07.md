# Board results, 2026-11-07

DE10-Lite (10M50DAF484C7G), 50 MHz, FPGA image from fpga/de10lite (Quartus Prime Lite 25.1:
31,762 LEs, 165/182 M9K, 136 multipliers, +2.103 ns setup slack at 50 MHz). UART through the
ESP32-S3's CH343 USB-serial chip (ESP32 held in reset) on COM8, 115200 baud. Commands from
docs/board_bringup.md; output copied as printed, except that the hello log's doubled blank
lines (a display bug in the first version of upload.py on Windows, since fixed) are removed.
